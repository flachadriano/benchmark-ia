# Visão do gestor

Somente quando o usuário for gestor, no header deve apresentar um botão "Gestão".

Quando clica no botão Gestão: Visão exclusiva do perfil gestor, para validar autorização e consultas com filtro.

- Consulta das horas da equipe por período, usuário e projeto;
- Destaque dos dias com apontamento abaixo de 8 horas;
- Exportação CSV da visão filtrada;

Devem ser criados testes automatizados que validem a implementação.
