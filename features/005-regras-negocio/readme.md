# Regras de negócio

Devem ser aplicadas as seguintes validações, no frontend e no backend:
- Hora de fim deve ser posterior à hora de início;
- Não permitir sobreposição de horários no mesmo dia para o mesmo usuário;
- Limite de 24 horas apontadas por dia;
- Alerta visual quando o dia fechar com menos de 8 horas apontadas;
- Mensagens de erro claras e iguais nas duas camadas;

Devem ser criados testes automatizados que validem a implementação.
