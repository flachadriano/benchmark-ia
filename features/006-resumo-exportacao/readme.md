# Resumo semanal e exportação

No header da aplicação deve ter um botão "Resumo"

Na tela de resumo: Consulta consolidada que exercita agregação no banco, visualização de dados e um endpoint que não é CRUD.

- Resumo da semana com total por dia e por projeto;
- Gráfico simples de horas por projeto na semana;
- Exportação dos apontamentos do período em CSV;

Devem ser criados testes automatizados que validem a implementação.
