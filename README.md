# benchmark-ia

## Especificação

Dentro da pasta `/features` tem a especificação das funcionalidades.

A estrutura de arquivos dentro da pasta `/features`:
- `/readme.md`: descrição do programador para a funcionalidade;
- `/spec.md`: especificação técnica detalhada criada pela IA;
- `/chat.md`: export do prompt e chat realizado para gerar a `/spec.md`;
- `/chat-develop.md`: export do prompt e chat realizado para implementação do `/spec.md`.
